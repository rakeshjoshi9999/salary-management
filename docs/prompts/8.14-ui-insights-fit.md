# 8.14 — The Insights page fits one screen; a quiet scrollbar

**Task:** `TASKS.md` 8.14 · **Date:** 2026-11-13 · **Tool:** Claude Code

## Prompt

> Insights card has weird black scroll background. change it to the transparent color so that it looks
> good. There is scroll still in the Insights page. Set the height of the Salary by title card so that I
> dont see scroll in the Insights page

Recorded as ADR-057. The local backend was stopped for memory and not restarted, so the new tests mock
the API in the browser; the backend-based Playwright suite runs in CI.

## Test list

Playwright, `e2e/insights-fit.e2e.ts` (desktop project, API mocked):

1. `doesNotScrollThePageAtDesktopSizes` — at 1280x800, 1440x900 and 1920x1080 the page has no scroll.
2. `keepsTheJobTitleCardTallEnoughToRead` — at 1280x800 the job-title card is at least 18 rem tall and
   its table scrolls inside it; at 1280x700, where the page must scroll, it is still at least 18 rem.
3. `endsTheJobTitleCardAtTheBottomOfTheScreen` — at 1280x800 the card's bottom is inside the viewport.
4. `drawsTheJobTitleScrollbarWithATransparentTrack` — in light and in dark, the scroll area has a thin
   scrollbar and its track colour is transparent.

Existing tests stay unchanged: the long-amount, tablet and phone checks, and axe in both themes.
