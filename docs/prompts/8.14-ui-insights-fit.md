# 8.14 — The Insights page fits one screen; a quiet scrollbar

**Task:** `TASKS.md` 8.14 · **Date:** 2026-11-13 · **Tool:** Claude Code

## Prompt

> Insights card has weird black scroll background. change it to the transparent color so that it looks
> good. There is scroll still in the Insights page. Set the height of the Salary by title card so that I
> dont see scroll in the Insights page

Recorded as ADR-057. The local backend was stopped for memory and not restarted, so the new tests mock
the API in the browser; the backend-based Playwright suite runs in CI.

## Test list

Playwright, `e2e/insights-fit.e2e.ts` (desktop project, API mocked):

1. `fitsOneScreenAt…` — at 1024x768, 1280x800, 1440x900 and 1920x1080 the page has no scroll and the
   job-title card's bottom is inside the viewport and within about 56 px of its bottom (it fills the
   space, with no gap).
2. `keepsTheJobTitleCardTallEnoughToRead…` — at 1280x800 the card is at least 18 rem tall and its table
   scrolls inside it.
3. `letsAShortScreenScrollThePageRatherThanCrushingTheCard` — at 1280x700 the page scrolls and the card
   is still at least 18 rem.
4. `drawsAThinScrollbarWithATransparentTrack` (light and dark) — `scrollbar-width: thin`, a fully
   transparent track and a visible thumb.
5. `changesTheScrollbarThumbWithTheTheme` — the thumb colour differs between light and dark.
6. `keepsTheScreenHeightCapAndPageScrollOnATablet` (768x1024) — a guard: below 1024 px the card is
   no taller than the screen, its table scrolls and the page scrolls (added after the implementation
   review).

Revised after the reviewer's pass: the fill check and the short-screen scroll are asserted, the thumb
must be visible, and 1024x768 covers the breakpoint.

Existing tests stay unchanged: the long-amount, tablet and phone checks, and axe in both themes.

## Notes

- Test review: the first tests only set upper bounds, so a short card leaving half the screen empty
  would have passed; the fill is now asserted at four sizes, the short-screen scroll is asserted, and
  the scrollbar test needs a visible thumb that differs between themes.
- The scrollbar thumb is slate-500 on white and slate-400 on slate-900 (4.8:1 and 6.5:1): quiet, and
  above the 3:1 non-text contrast. The reviewer first caught a 2.6:1 light thumb.
- Not run: the backend-based Playwright suite (the local backend was stopped for memory and was not
  restarted unasked); CI runs it on the push. The Catalog's inner scroll keeps the default scrollbar.

## Outcome

On a 1024 px or wider screen at least 600 px tall the Insights page fits one screen, the job-title card
filling the space under the tiles, and its scroll area has a thin, transparent-track scrollbar.
197 unit tests green; the 9 new Playwright checks (mocked API) green.
