## Outcome

ADR-019 to ADR-025 written. The "Still pending" list in `DECISIONS.md` is closed with a pointer to each.

Where the reason was something only the engineer knew, the AI asked for it instead of supplying one.
That is how two reasons got recorded accurately:
- The stack came from the brief, not from an evaluation on merit.
- **Java 21 was kept because it is the installed JDK**, not because anything required it. Java 25 is
  recorded as deferred.

These items were nominally "already decided", but each hid an open design question, now settled:
- **Money in Java:** plain `BigDecimal` with one rounding helper, not a value object or Moneta.
- **Insight SQL:** `JdbcClient` in its own repository, since JPQL has no window functions for the
  exact median.
- **Optimistic locking:** `@Version` plus an explicit version check, because `@Version` alone silently
  ignores a stale client version on a load-copy-save PUT.
- **A hosting ADR (ADR-025)** was added. No ADR had said why Render and Vercel.
