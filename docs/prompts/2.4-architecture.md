## Outcome

[`ARCHITECTURE.md`](../ARCHITECTURE.md) has five Mermaid diagrams: deployment, backend components,
frontend components, a stale-update sequence and an insights sequence. ADR-026 records the structure.

Every recommendation was accepted:
- Feature packages with layers inside.
- One-way dependencies on `reference`.
- Reference data held in memory.
- A frontend `core/` folder.
- Rules enforced by review rather than ArchUnit.

`CorsConfig` stays in the root package until the first phase 3 slice, so this task stays docs-only.
The Mermaid was written by hand and not run through a renderer. Check it on GitHub.
