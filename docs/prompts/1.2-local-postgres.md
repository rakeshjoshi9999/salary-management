## Outcome

`docker-compose.yml` with Postgres pinned to the same major version as the test
container, and datasource, credentials and port all read from environment variables
with local defaults.

Two things Claude found rather than was told:

- Host port 5432 was already occupied on this machine, so compose publishes 5433.
- Port 8080 was occupied by another project's container, so the backend's local
  default is 8081 — which later had to be made consistent with the Angular dev
  environment in a follow-up commit.

Verified by booting the app against the compose database and confirming Flyway created
its history table there.
