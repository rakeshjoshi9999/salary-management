## Outcome

`frontend/vercel.json` pins the framework, install and build commands, the output
directory and a catch-all rewrite to `index.html` so refreshing a route does not 404.

**Root Directory had to stay a dashboard setting.** Claude checked Vercel's full
`vercel.json` property table rather than assuming, and `rootDirectory` is not among them —
it is a project-level setting only. So one field was set by hand and everything else
committed, which also means the build config is reviewable rather than clicked.

Verified rather than taken on trust: the root returns 200, a deep link returns 200 so the
rewrite works, and the production bundle contains the Render host with zero occurrences of
the localhost dev value — confirming Angular's `fileReplacements` swapped `environment.ts`
correctly.

Claude had earlier guessed both the Vercel and Render hostnames and been wrong on both;
Render appends a random suffix when a service name is taken globally, and neither URL is
derivable from the repository.
