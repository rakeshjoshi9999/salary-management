The engineer overrode the AI once: **money is a JSON number**, not a string. The consequence is now a

While writing it up, the AI caught two errors in **its own option text**, already answered, and
recorded both corrections in ADR-017:
- It had offered `percentile_cont(0.5)` for the median. That works in `double precision` in Postgres,

- Postgres `round(numeric)` rounds ties away from zero, not `HALF_EVEN`. Final rounding therefore
  moves to Java.
