# 8.9 — UI redesign, Insights

**Task:** `TASKS.md` 8.9 · **Date:** 2026-11-13 · **Tool:** Claude Code

Second of the five redesign tasks (ADR-054); the prompt and decisions are in
[`8.8-ui-foundation.md`](8.8-ui-foundation.md). The engineer asked for 8.8–8.12 in one session, so this
list went straight to failing tests; it is recorded here as the slice's acceptance criteria.

## Layout

A bento grid. Desktop (4 columns): a tall Median hero tile over two columns and two rows, four small
tiles beside it (headcount, average, min, max), then the job-title bars and the department doughnut side
by side. Tablet: 2 columns. Phone: 1 column. The country picker moves into the page header. Money stays
in full on one line; type steps down with container queries instead of wrapping.

## Test list

Unit, `insights/insights-page.spec.ts` (new tests):

1. `laysOutTheMetricsAsABentoGrid` — an `insights-bento` grid holds, in order: median, headcount,
   average, min, max, job titles, departments.
2. `explainsTheMedianInTheHeroTile` — the median tile says "Half of the 3,500 employees in India earn
   this or less, and half this or more." (First drafted as "earn less than this", which is false when
   salaries tie at the median; corrected after the implementation review.)
2a. `describesAMedianOfOneEmployeeWithoutHalves` — with one employee: "This is the salary of India's one
   employee."
3. `putsTheCountryPickerInThePageHeader` — the country select is inside the page header.

Unit, `insights/department-doughnut.spec.ts` (new file):

4. `usesTheLightPaletteOnALightPage` — slice colours are the light palette, outlines are white.
5. `switchesToTheDarkPaletteWhenTheThemeTurnsDark` — slices use the dark palette, outlines the dark
   card colour (slate-900), without a reload.
6. `keepsEverySliceAtThreeToOneAgainstTheCard` — every colour in each palette has at least 3:1 contrast
   with that mode's card (WCAG 1.4.11).
7. `matchesTheLegendSwatchesToTheSlices` — legend swatch i has slice i's colour, in light and in dark.

Unit, `core/theme.spec.ts`:

8. `treatsAMissingMatchMediaAsALightOs` — where `matchMedia` does not exist (jsdom, old browsers), the
   default `MATCH_MEDIA` reports a light OS instead of throwing.
9. `keepsTheChoiceInMemoryWhenLocalStorageIsUnreachable` — when reading `window.localStorage` throws
   (blocked site data), the default `THEME_STORAGE` still stores and returns the choice for this visit.
   The fix shipped in 8.8 after its implementation review; this is its test.

Playwright, `e2e/insights.e2e.ts` (desktop and phone):

10. `fitsTheLongestAmountsOnOneLineInEveryTile` — with the API answering its longest amount
    (`999,999,999,999.99`: `Money` in openapi.yaml, NUMERIC(14,2)), every money value in the tiles,
    the job-title amounts included, stays on one line inside its tile, at 1280, 1024, 768 and 390 px.
    The decision question had said "13-digit"; the reviewer found that contradicts the API's 12-digit
    cap, so the test follows the design docs.

Existing tests stay unchanged: the five values, bars, legend, total, country, empty, error and skeleton
behaviour, and the axe checks of 8.8 now cover the bento in both modes.
