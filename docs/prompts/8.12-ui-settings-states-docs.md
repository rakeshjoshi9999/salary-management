# 8.12 — UI redesign, Settings, states and docs

**Task:** `TASKS.md` 8.12 · **Date:** 2026-11-13 · **Tool:** Claude Code

Last of the five redesign tasks (ADR-054); the prompt and decisions are in
[`8.8-ui-foundation.md`](8.8-ui-foundation.md). The engineer asked for 8.8–8.12 in one session, so this
list went straight to failing tests; it is recorded here as the slice's acceptance criteria.

## Scope

Settings becomes a card section with a heading and a line on what the setting does. Empty and error
panels lead with an icon. `UI_DESIGN.md` is brought up to the new screens (ADR-054, ADR-055), the README
screenshots are retaken from the seeded local stack, and `CHANGELOG.md` and `AI_USAGE.md` get the
redesign.

## Test list

1. `introducesTheDefaultCountryWithAHeadingAndWhatItDoes` — the settings card has an `h3` "Default
   country" and says "Insights opens on this country".
2. `showsADecorativeIconInTheEmptyState` and 3. `…InTheErrorState` — an icon, hidden from screen readers.

The docs are checked by reading them against the code, as in 8.1–8.3. The axe checks of 8.8 cover
Settings in both modes.

## Notes

- Docs review: the reviewer checked every claim against the code and found overclaims, all fixed: the
  Insights breakpoint is 768 px, not 640; axe covers four scenes, not every screen; two empty or error
  panels have no icon; the bars take 600 ms; and the AI_USAGE counts and filing. The first Insights
  screenshot showed salaries edited by E2E runs, so the local database was reset, re-seeded and the
  shot retaken before any test ran.
