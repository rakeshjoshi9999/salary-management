## Scope

Settings becomes a card section with a heading and a line on what the setting does. Empty and error
panels lead with an icon. `UI_DESIGN.md` is brought up to the new screens (ADR-054, ADR-055), the README
screenshots are retaken from the seeded local stack, and `CHANGELOG.md` and `AI_USAGE.md` get the
redesign.
