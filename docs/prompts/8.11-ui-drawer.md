# 8.11 — UI redesign, employee drawer

**Task:** `TASKS.md` 8.11 · **Date:** 2026-11-13 · **Tool:** Claude Code

Fourth of the five redesign tasks (ADR-054); the prompt and decisions are in
[`8.8-ui-foundation.md`](8.8-ui-foundation.md). The engineer asked for 8.8–8.12 in one session, so this
list went straight to failing tests; it is recorded here as the slice's acceptance criteria.

## Layout

View: a profile header (initials avatar, name, email with a copy button, department badge), a salary
block, a details list (title, country and currency, hire date with tenure), Edit, and Delete in a danger
area at the bottom. Edit and add: the fields grouped as Person (name, email), Role (department, job
title, hire date) and Pay (country, salary, whose currency follows the country), with Cancel and Save
in a footer that stays in view. Validation, the dependent title list, 409 handling and the
unsaved-changes guard are unchanged.
